# CuiForm 表单组件

CuiForm 是基于 Element Plus Form 组件封装的增强型表单组件，提供了动态字段渲染、表单验证、多种字段类型支持等功能。

## 基础用法

使用 `fields` 和 `v-model` 定义表单字段配置和数据绑定。

::component-demo
---
title: 基础表单
description: 最简单的表单用法，展示基本的数据输入功能
---
#preview
<CuiForm
  ref="formRef"
  v-model="formData"
  :fields="fields"
/>
<el-button type="primary" @click="handleSubmit">提交</el-button>

#code
```vue
<template>
  <CuiForm
    ref="formRef"
    v-model="formData"
    :fields="fields"
  />
  <el-button type="primary" @click="handleSubmit">提交</el-button>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const formRef = ref();
const formData = ref({
  name: '',
  email: '',
  age: 0,
});

const fields: CuiFormField[] = [
  {
    prop: 'name',
    label: '姓名',
    type: 'input',
    placeholder: '请输入姓名',
    required: true,
  },
  {
    prop: 'email',
    label: '邮箱',
    type: 'input',
    placeholder: '请输入邮箱',
    required: true,
  },
  {
    prop: 'age',
    label: '年龄',
    type: 'number',
    placeholder: '请输入年龄',
  },
];

const handleSubmit = async () => {
  const result = await formRef.value?.submit();
  if (result?.valid) {
    console.log('表单数据:', formData.value);
  }
};
</script>
```

## 表单验证

通过 `required` 属性和 `rules` 属性配置表单验证规则。

::component-demo
---
title: 表单验证
description: 支持必填验证、格式验证、自定义验证规则
---
#preview
<CuiForm
  ref="formRef"
  v-model="formData"
  :fields="fields"
/>
<el-button type="primary" @click="handleSubmit">提交</el-button>
<el-button @click="handleReset">重置</el-button>

#code
```vue
<template>
  <CuiForm
    ref="formRef"
    v-model="formData"
    :fields="fields"
  />
  <el-button type="primary" @click="handleSubmit">提交</el-button>
  <el-button @click="handleReset">重置</el-button>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const formRef = ref();
const formData = ref({
  username: '',
  email: '',
  phone: '',
  password: '',
});

const fields: CuiFormField[] = [
  {
    prop: 'username',
    label: '用户名',
    type: 'input',
    placeholder: '请输入用户名',
    required: true,
    rules: [
      { min: 3, max: 20, message: '用户名长度在 3 到 20 个字符', trigger: 'blur' },
    ],
  },
  {
    prop: 'email',
    label: '邮箱',
    type: 'input',
    placeholder: '请输入邮箱',
    required: true,
    rules: [
      { type: 'email', message: '请输入正确的邮箱格式', trigger: 'blur' },
    ],
  },
  {
    prop: 'phone',
    label: '手机号',
    type: 'input',
    placeholder: '请输入手机号',
    rules: [
      { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号', trigger: 'blur' },
    ],
  },
  {
    prop: 'password',
    label: '密码',
    type: 'input',
    placeholder: '请输入密码',
    required: true,
    rules: [
      { min: 6, message: '密码长度不能少于 6 个字符', trigger: 'blur' },
    ],
  },
];

const handleSubmit = async () => {
  const result = await formRef.value?.submit();
  if (result?.valid) {
    console.log('验证通过，表单数据:', formData.value);
  } else {
    console.log('验证失败:', result?.errors);
  }
};

const handleReset = () => {
  formRef.value?.resetFields();
};
</script>
```

## 自定义字段

通过 `slot` 属性和具名插槽自定义字段渲染。

::component-demo
---
title: 自定义字段
description: 使用插槽自定义字段渲染，实现复杂的表单控件
---

  v-model="formData"
  :fields="fields"
>
  <template #customField="{ value, updateValue }">
    <el-slider
      :model-value="value"
      :min="0"
      :max="100"
      @update:model-value="updateValue"
    />
  </template>
</CuiForm>

#code
```vue
<template>
  <CuiForm
    v-model="formData"
    :fields="fields"
  >
    <template #customField="{ value, updateValue }">

        :model-value="value"
        :min="0"
        :max="100"
        @update:model-value="updateValue"
      />
    </template>
  </CuiForm>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const formData = ref({
  name: '',
  score: 50,
});

const fields: CuiFormField[] = [
  {
    prop: 'name',
    label: '姓名',

    placeholder: '请输入姓名',

</script>
```

## Props

| 属性名 | 类型 | 默认值 | 必需 | 说明 |
|--------|------|--------|------|------|
| fields | `CuiFormField<T>[]` | - | 是 | 表单字段配置数组 |
| modelValue | `T` | - | 是 | 表单数据（双向绑定） |
| labelWidth | `string \| number` | `'100px'` | 否 | 标签宽度 |
| inline | `boolean` | `false` | 否 | 是否行内表单 |
| disabled | `boolean` | `false` | 否 | 是否禁用整个表单 |
| labelPosition | `'left' \| 'right' \| 'top'` | `'right'` | 否 | 标签位置 |

### CuiFormField 类型说明

| 属性名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| prop | `string` | 是 | 字段属性名（对应数据对象的 key） |
| label | `string` | 是 | 字段标签 |
| type | `'input' \| 'select' \| 'date' \| 'textarea' \| 'number'` | 是 | 字段类型 |
| placeholder | `string` | 否 | 占位符文本 |
| required | `boolean` | 否 | 是否必填 |
| rules | `FormItemRule[]` | 否 | 验证规则 |
| options | `CuiFormSelectOption[]` | 否 | 选择框选项（type 为 select 时使用） |
| disabled | `boolean` | 否 | 是否禁用 |
| defaultValue | `any` | 否 | 默认值 |
| slot | `string` | 否 | 自定义插槽名称（用于复杂的自定义渲染） |

## Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| update:modelValue | `(value: T)` | 表单数据更新时触发（用于 v-model） |
| submit | `(value: T)` | 表单提交时触发（验证通过后） |
| reset | `()` | 表单重置时触发 |

## Slots

| 插槽名 | 作用域参数 | 说明 |
|--------|------------|------|
| [field.slot] | `{ field: CuiFormField, value: any, updateValue: (val: any) => void }` | 自定义字段内容，通过 field 配置的 slot 属性指定插槽名 |

## Methods（通过 ref 调用）

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| validate | `()` | `Promise<CuiFormValidateResult>` | 验证整个表单 |
| validateField | `(prop: string)` | `Promise<boolean>` | 验证指定字段 |
| resetFields | `()` | `void` | 重置表单 |
| clearValidate | `(props?: string \| string[])` | `void` | 清除验证 |
| submit | `()` | `Promise<CuiFormValidateResult>` | 提交表单（验证后触发 submit 事件） |

## 类型定义

```typescript
type CuiFormFieldType = 'input' | 'select' | 'date' | 'textarea' | 'number';

interface CuiFormSelectOption {
  label: string;
  value: any;
  disabled?: boolean;
}

interface CuiFormField<T = any> {
  prop: keyof T & string;
  label: string;
  type: CuiFormFieldType;
  placeholder?: string;
  required?: boolean;
  rules?: FormItemRule[];
  options?: CuiFormSelectOption[];
  disabled?: boolean;
  defaultValue?: any;
  slot?: string;
}

interface CuiFormProps<T = any> {
  fields: CuiFormField<T>[];
  modelValue: T;
  labelWidth?: string | number;
  inline?: boolean;
  disabled?: boolean;
  labelPosition?: 'left' | 'right' | 'top';
}

interface CuiFormValidateResult {
  valid: boolean;
  errors?: Record<string, string[]>;
}
```

## 注意事项

::callout{type="warning"}
1. `fields` 和 `modelValue` 是必需的属性
2. 使用自定义插槽时，需要在字段配置中设置 `slot` 属性
3. 验证规则遵循 Element Plus Form 的验证规则格式
4. 组件基于 Element Plus Form，通过 `v-bind="$attrs"` 透传其他 props 和事件
5. 支持 TypeScript 泛型，可以为表单数据指定类型
6. 表单提交前会自动进行验证，验证失败时不会触发 `submit` 事件
7. 必填字段会自动添加验证规则
8. 支持 5 种内置字段类型：input、textarea、number、select、date
9. 可以通过 slot 自定义字段渲染
::
