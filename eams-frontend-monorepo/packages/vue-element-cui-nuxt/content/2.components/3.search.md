# CuiSearch 搜索组件

CuiSearch 是基于 Element Plus Form 组件封装的搜索表单组件，提供了快速构建搜索表单的能力，支持多种字段类型和高级搜索折叠功能。

## 基础用法

使用 `fields` 属性定义搜索字段配置，使用 `v-model` 绑定表单数据。

::component-demo
---
title: 基础搜索表单
description: 最简单的搜索表单用法，展示基本的搜索和重置功能
---
#preview
<CuiSearch
  v-model="searchForm"
  :fields="fields"
  @search="handleSearch"
  @reset="handleReset"
/>

#code
```vue
<template>
  <CuiSearch
    v-model="searchForm"
    :fields="fields"
    @search="handleSearch"
    @reset="handleReset"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiSearchField } from '@eams/vue-element-cui';

const searchForm = ref({});

const fields: CuiSearchField[] = [
  { prop: 'name', label: '姓名', type: 'input', placeholder: '请输入姓名' },
  { prop: 'email', label: '邮箱', type: 'input', placeholder: '请输入邮箱' },
];

const handleSearch = (values: any) => {
  console.log('搜索:', values);
};

const handleReset = (values: any) => {
  console.log('重置:', values);
};
</script>
```
::

## API 参考

### CuiSearchProps

| 属性名 | 类型 | 默认值 | 必需 | 说明 |
|--------|------|--------|------|------|
| fields | `CuiSearchField[]` | - | 是 | 搜索字段配置数组 |
| modelValue | `Record<string, any>` | - | 是 | 表单值（支持 v-model） |
| inline | `boolean` | `true` | 否 | 是否内联布局 |
| collapsible | `boolean` | `true` | 否 | 是否可折叠高级搜索 |

### CuiSearchField

| 属性名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| prop | `string` | 是 | 字段属性名（对应数据对象的 key） |
| label | `string` | 是 | 字段标签 |
| type | `'input' \| 'select' \| 'date' \| 'daterange'` | 是 | 字段类型 |
| placeholder | `string` | 否 | 占位符文本 |
| options | `Array<{ label: string; value: any }>` | 否 | 选项列表（用于 select 类型） |
| advanced | `boolean` | 否 | 是否为高级搜索字段 |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| update:modelValue | `(value: Record<string, any>)` | 表单值更新时触发（用于 v-model） |
| search | `(value: Record<string, any>)` | 点击搜索按钮时触发 |
| reset | `(value: Record<string, any>)` | 点击重置按钮时触发 |

## 类型定义

```typescript
interface CuiSearchField {
  prop: string;
  label: string;
  type: 'input' | 'select' | 'date' | 'daterange';
  placeholder?: string;
  options?: Array<{ label: string; value: any }>;
  advanced?: boolean;
}

interface CuiSearchProps {
  fields: CuiSearchField[];
  modelValue: Record<string, any>;
  inline?: boolean;
  collapsible?: boolean;
}
```

## 最佳实践

::callout{type="info"}
**字段配置**

合理组织基础搜索字段和高级搜索字段，将常用字段放在基础搜索中。
::

::callout{type="info"}
**选项数据**

对于 select 类型，建议将选项数据定义为常量或从后端获取。
::

::callout{type="info"}
**搜索逻辑**

在 `search` 事件中执行实际的搜索逻辑，可以结合 CuiTable 组件使用。
::

::callout{type="info"}
**重置逻辑**

重置后可以选择是否自动触发一次搜索，根据业务需求决定。
::

::callout{type="info"}
**布局选择**

字段较多时建议使用非内联布局（`inline: false`），提高可读性。
::

## 注意事项

::callout{type="warning"}
1. `fields` 和 `modelValue` 是必需的属性
2. 使用 `v-model` 绑定表单数据，支持双向绑定
3. 高级搜索字段需要在字段配置中设置 `advanced: true`
4. `collapsible` 属性控制高级搜索是否可折叠，默认为 `true`
5. 点击重置按钮会清空所有字段值
6. 组件基于 Element Plus Form，通过 `v-bind="$attrs"` 透传其他 props
7. 支持基础搜索和高级搜索字段分组
8. 高级搜索字段可折叠/展开
9. 所有字段自动支持清空功能
::
