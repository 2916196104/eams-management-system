# CuiExcel

`CuiExcel` 负责把上传、模板下载和结果反馈整合到统一流程里，适合数据导入场景。

<FeatureList
	:items="[
		{ title: '模板与字段说明配套', description: '导入链路必须配套模板下载与字段说明，避免用户凭猜测上传。' },
		{ title: '导入结果必须可追溯', description: '上传成功、失败和异常原因要清晰返回到业务页，而不是留在隐式状态里。' },
		{ title: '上传链路显式配置', description: '上传地址、请求头和额外参数都应由业务侧显式配置。' },
	]"
/>

::api-table{title="核心 Props" description="导入流程最常用配置"}
| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `modelValue` | `boolean` | 弹层是否打开 |
| `uploadUrl` | `string` | 上传地址 |
| `templateUrl` | `string` | 模板下载地址 |
| `headers` | `Record<string, string>` | 请求头 |
| `params` | `Record<string, any>` | 额外参数 |
::

::doc-note{title="扩展说明" tone="warning"}
虽然 `CuiExcel` 具备明显的业务增强属性，但为了方便查找，当前仍放在数据展示体系下说明；扩展能力栏目会继续沉淀同类组件入口。
::
