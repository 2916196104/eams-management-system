# CuiDetail

`CuiDetail` 用于展示结构化详情信息，适合用户信息、工单信息和审批记录等场景。

<FeatureList
	:items="[
		{ title: '字段驱动详情布局', description: '通过 fields 和 data 描述详情布局，不必在页面里重复写 label / value 结构。' },
		{ title: '多列组织信息块', description: '支持按列数组织详情展示，适合信息密度较高的管理后台。' },
		{ title: 'render 承接格式化展示', description: '当字段需要状态映射、时间格式化或金额处理时，可使用 render。' },
	]"
/>

::api-table{title="核心 Props" description="详情页常用配置"}
| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `fields` | `CuiDetailField[]` | 字段配置 |
| `data` | `Record<string, any>` | 详情数据 |
| `columns` | `number` | 布局列数，默认 `2` |
| `labelWidth` | `string` | 标签宽度 |
::

## 推荐写法

```vue
<script setup lang="ts">
import { CuiDetail } from "@eams/vue-element-cui";
import type { CuiDetailField } from "@eams/vue-element-cui";

const fields: CuiDetailField[] = [
	{ label: "资产名称", prop: "name" },
	{ label: "负责人", prop: "owner" },
	{ label: "状态", prop: "status", render: (row) => (row.status === 1 ? "启用" : "停用") },
];

const detail = {
	name: "固定资产台账",
	owner: "财务共享中心",
	status: 1,
};
</script>

<template>
	<CuiDetail :fields="fields" :data="detail" />
</template>
```
