# CuiDialogForm 对话框表单组件

CuiDialogForm 是一个结合了对话框和表单功能的组件，用于在对话框中展示和提交表单数据。

## 基础用法

使用 `visible`、`fields` 和 `v-model` 定义对话框表单。

::component-demo
---
title: 基础对话框表单
description: 最简单的对话框表单用法，展示基本的表单提交功能
---
#preview
<div>
  <el-button @click="visible = true">打开表单对话框</el-button>
  <CuiDialogForm
    v-model:visible="visible"
    v-model="formData"
    title="用户信息"
    :fields="formFields"
    @submit="handleSubmit"
  />
</div>

#code
```vue
<template>
  <div>
    <el-button @click="visible = true">打开表单对话框</el-button>
    <CuiDialogForm
      v-model:visible="visible"
      v-model="formData"
      title="用户信息"
      :fields="formFields"
      @submit="handleSubmit"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const visible = ref(false);
const formData = ref({ name: '', email: '' });

const formFields: CuiFormField[] = [
  {
    prop: 'name',
    label: '姓名',
    type: 'input',
    placeholder: '请输入姓名',
  },
  {
    prop: 'email',
    label: '邮箱',
    type: 'input',
    placeholder: '请输入邮箱',
  },
];

const handleSubmit = (data: any) => {
  console.log('提交数据:', data);
  visible.value = false;
};
</script>
```
::

## 加载状态

通过 `loading` 属性显示提交加载状态，防止重复提交。

::component-demo
---
title: 加载状态
description: 使用 loading 属性在提交时显示加载状态
---
#preview
<div>
  <el-button @click="visible = true">打开表单</el-button>
  <CuiDialogForm
    v-model:visible="visible"
    v-model="formData"
    title="提交表单"
    :fields="formFields"
    :loading="isSubmitting"
    @submit="handleSubmit"
  />
</div>

#code
```vue
<template>
  <div>
    <el-button @click="visible = true">打开表单</el-button>
    <CuiDialogForm
      v-model:visible="visible"
      v-model="formData"
      title="提交表单"
      :fields="formFields"
      :loading="isSubmitting"
      @submit="handleSubmit"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const visible = ref(false);
const isSubmitting = ref(false);
const formData = ref({ title: '', content: '' });

const formFields: CuiFormField[] = [
  { prop: 'title', label: '标题', type: 'input', placeholder: '请输入标题' },
  { prop: 'content', label: '内容', type: 'textarea', placeholder: '请输入内容' },
];

const handleSubmit = async (data: any) => {
  isSubmitting.value = true;
  try {
    // 模拟异步提交
    await new Promise(resolve => setTimeout(resolve, 2000));
    console.log('提交成功:', data);
    visible.value = false;
  } finally {
    isSubmitting.value = false;
  }
};
</script>
```
::

## 编程式控制

通过 ref 调用组件方法，如 `setFormData` 和 `resetForm`。

::component-demo
---
title: 编程式控制
description: 使用 ref 调用组件方法，动态设置表单数据
---
#preview
<div>
  <el-button @click="openForm">编辑用户</el-button>
  <CuiDialogForm
    ref="dialogFormRef"
    v-model:visible="visible"
    v-model="formData"
    title="编辑用户"
    :fields="formFields"
    @submit="handleSubmit"
  />
</div>

#code
```vue
<template>
  <div>
    <el-button @click="openForm">编辑用户</el-button>
    <CuiDialogForm
      ref="dialogFormRef"
      v-model:visible="visible"
      v-model="formData"
      title="编辑用户"
      :fields="formFields"
      @submit="handleSubmit"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiFormField } from '@eams/vue-element-cui';

const dialogFormRef = ref();
const visible = ref(false);
const formData = ref({ name: '', email: '' });

const formFields: CuiFormField[] = [
  { prop: 'name', label: '姓名', type: 'input', placeholder: '请输入姓名' },
  { prop: 'email', label: '邮箱', type: 'input', placeholder: '请输入邮箱' },
];

const openForm = () => {
  // 模拟获取用户数据
  const userData = { name: 'John', email: 'john@example.com' };
  dialogFormRef.value?.setFormData(userData);
  visible.value = true;
};

const handleSubmit = (data: any) => {
  console.log('提交:', data);
  visible.value = false;
};
</script>
```

## API 参考

### Props

| 属性名 | 类型 | 默认值 | 必需 | 说明 |
|--------|------|--------|------|------|
| visible | `boolean` | - | 是 | 对话框是否显示 |
| modelValue | `T` | - | 是 | 表单数据 |
| title | `string` | `'表单对话框'` | 否 | 对话框标题 |
| width | `string \| number` | `'50%'` | 否 | 对话框宽度 |
| showClose | `boolean` | `true` | 否 | 是否显示关闭按钮 |
| closeOnClickModal | `boolean` | `false` | 否 | 点击遮罩层是否关闭对话框 |
| fields | `CuiFormField<T>[]` | - | 是 | 表单字段配置 |
| labelWidth | `string \| number` | `'100px'` | 否 | 标签宽度 |
| inline | `boolean` | `false` | 否 | 是否行内表单 |
| disabled | `boolean` | `false` | 否 | 是否禁用整个表单 |
| labelPosition | `'left' \| 'right' \| 'top'` | `'right'` | 否 | 标签位置 |
| confirmText | `string` | `'确认'` | 否 | 确认按钮文本 |
| cancelText | `string` | `'取消'` | 否 | 取消按钮文本 |
| confirmDisabled | `boolean` | `false` | 否 | 是否禁用确认按钮 |
| loading | `boolean` | `false` | 否 | 是否显示加载状态 |

### Events

| 事件名 | 参数 | 说明 |
|--------|------|------|
| update:visible | `(value: boolean)` | 对话框显示状态更新 |
| update:modelValue | `(value: T)` | 表单数据更新 |
| submit | `(value: T)` | 表单提交（验证通过后） |
| cancel | `()` | 取消按钮点击 |
| open | `()` | 对话框打开 |
| close | `()` | 对话框关闭 |

### Slots

| 插槽名 | 作用域参数 | 说明 |
|--------|------------|------|
| default | - | 对话框顶部内容 |
| footer-center | - | 底部按钮中间的自定义内容 |
| field-[prop] | `{ field, value, updateValue }` | 自定义表单字段，[prop] 为字段的 prop 值 |

### Methods（通过 ref 调用）

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| resetForm | `()` | `void` | 重置表单 |
| setFormData | `(data: any)` | `void` | 设置表单数据 |

## 表单字段配置

表单字段配置遵循 CuiForm 的字段配置规范。

```typescript
interface CuiFormField<T = any> {
  prop: keyof T & string;
  label: string;
  type: 'input' | 'select' | 'date' | 'textarea' | 'number';
  placeholder?: string;
  required?: boolean;
  rules?: FormItemRule[];
  options?: Array<{ label: string; value: any }>;
  disabled?: boolean;
  defaultValue?: any;
  slot?: string;
}
```

## 类型定义

```typescript
interface CuiDialogFormProps<T = any> {
  visible: boolean;
  modelValue: T;
  title?: string;
  width?: string | number;
  showClose?: boolean;
  closeOnClickModal?: boolean;
  fields: CuiFormField<T>[];
  labelWidth?: string | number;
  inline?: boolean;
  disabled?: boolean;
  labelPosition?: 'left' | 'right' | 'top';
  confirmText?: string;
  cancelText?: string;
  confirmDisabled?: boolean;
  loading?: boolean;
}
```

## 注意事项

::callout{type="warning"}
1. `visible`、`modelValue` 和 `fields` 是必需的属性
2. 使用 `v-model:visible` 和 `v-model` 可以简化双向绑定
3. 组件结合了 CuiDialog 和 CuiForm
4. 提交时自动进行表单验证
5. 验证通过后才会触发 submit 事件并关闭对话框
6. 使用 `loading` 属性可以在提交时显示加载状态，防止重复提交
7. 通过 `ref` 可以调用组件方法，如 `resetForm` 和 `setFormData`
8. 支持自定义插槽来扩展对话框内容和表单字段
::
