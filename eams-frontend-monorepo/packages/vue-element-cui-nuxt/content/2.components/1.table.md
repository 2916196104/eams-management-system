# CuiTable 表格组件

CuiTable 是基于 Element Plus Table 组件封装的增强型表格组件，提供了更简洁的 API 和常用功能的快速配置。

## 基础用法

使用 `data` 和 `columns` 属性定义表格数据和列配置。

::component-demo
---
title: 基础表格
description: 最简单的表格用法，展示基本的数据展示功能
---
#preview
<CuiTable :data="tableData" :columns="columns" />

#code
```vue
<template>
  <CuiTable :data="tableData" :columns="columns" />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import type { CuiTableColumn } from '@eams/vue-element-cui';

const tableData = ref([
  { id: 1, name: '张三', age: 25, email: 'zhangsan@example.com' },
  { id: 2, name: '李四', age: 30, email: 'lisi@example.com' },
  { id: 3, name: '王五', age: 28, email: 'wangwu@example.com' },
]);

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'email', label: '邮箱' },
];
</script>
```

## 自定义排序

设置 `sortable: 'custom'` 实现自定义排序逻辑。

::component-demo
---
title: 自定义排序
description: 使用 sortable: 'custom' 实现自定义排序逻辑，适用于复杂排序场景
---
#preview
<CuiTable
  :data="sortedData"
  :columns="columns"
  @sort-change="handleSortChange"
/>

#code
```vue
<template>
  <CuiTable
    :data="sortedData"
    :columns="columns"
    @sort-change="handleSortChange"
  />
</template>

<script setup lang="ts">
import { ref, computed } from 'vue';
import type { CuiTableColumn } from '@eams/vue-element-cui';

const tableData = ref([
  { id: 1, name: '张三', age: 25 },
  { id: 2, name: '李四', age: 30 },
  { id: 3, name: '王五', age: 28 },
  { id: 4, name: '赵六', age: 22 },
]);

const sortConfig = ref({ prop: '', order: null });

const sortedData = computed(() => {
  if (!sortConfig.value.order) return tableData.value;

  return [...tableData.value].sort((a, b) => {
    const prop = sortConfig.value.prop;
    const order = sortConfig.value.order === 'ascending' ? 1 : -1;
    return (a[prop] > b[prop] ? 1 : -1) * order;
  });
});

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名', sortable: 'custom' },
  { prop: 'age', label: '年龄', sortable: 'custom' },
];

const handleSortChange = (event: any) => {
  sortConfig.value = event;
};
</script>
```

## API 参考

### Props

| 属性名 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| data | `T[]` | - | 表格数据数组（必需） |
| columns | `CuiTableColumn<T>[]` | - | 列配置数组（必需） |
| loading | `boolean` | `false` | 是否显示加载状态 |
| showIndex | `boolean` | `false` | 是否显示索引列 |
| showSelection | `boolean` | `false` | 是否显示选择列 |
| stripe | `boolean` | `false` | 是否显示斑马纹 |
| border | `boolean` | `true` | 是否显示边框 |
| height | `string \| number` | - | 表格高度 |
| maxHeight | `string \| number` | - | 表格最大高度 |

### CuiTableColumn 类型说明

| 属性名 | 类型 | 说明 |
| --- | --- | --- |
| prop | `string` | 列属性名（对应数据对象的 key） |
| label | `string` | 列标题（必需） |
| width | `string \| number` | 列宽度 |
| minWidth | `string \| number` | 最小列宽度 |
| sortable | `boolean \| 'custom'` | 是否可排序，设置为 'custom' 时需自行处理排序逻辑 |
| fixed | `boolean \| 'left' \| 'right'` | 列是否固定在左侧或右侧 |
| align | `'left' \| 'center' \| 'right'` | 对齐方式 |
| formatter | `(row, column, cellValue, index) => any` | 格式化函数，用于简单的文本格式化 |
| slot | `string` | 自定义插槽名称，用于复杂的自定义渲染 |

### Events

| 事件名 | 参数 | 说明 |
| --- | --- | --- |
| sort-change | `{ prop: string, order: 'ascending' \| 'descending' \| null }` | 排序变化时触发 |
| selection-change | `selection: T[]` | 选择项变化时触发，返回选中的行数组 |
| row-click | `(row: T, column: any, event: Event)` | 行点击时触发 |
| cell-click | `(row: T, column: any, cell: any, event: Event)` | 单元格点击时触发 |

::callout{type="info"}
组件通过 `v-bind="$attrs"` 继承了 Element Plus Table 的所有其他 props 和事件，因此支持所有 ElTable 的原生功能。
::

### Slots

| 插槽名 | 作用域参数 | 说明 |
| --- | --- | --- |
| [column.slot] | `{ row: T, column: CuiTableColumn, $index: number }` | 自定义列内容，通过 column 配置的 slot 属性指定插槽名 |

## 类型定义

```typescript
interface CuiTableColumn<T = any> {
  prop?: string;
  label: string;
  width?: string | number;
  minWidth?: string | number;
  sortable?: boolean | 'custom';
  fixed?: boolean | 'left' | 'right';
  align?: 'left' | 'center' | 'right';
  formatter?: (row: T, column: any, cellValue: any, index: number) => any;
  slot?: string;
}

interface CuiTableProps<T = any> {
  data: T[];
  columns: CuiTableColumn<T>[];
  loading?: boolean;
  showIndex?: boolean;
  showSelection?: boolean;
  stripe?: boolean;
  border?: boolean;
  height?: string | number;
  maxHeight?: string | number;
}

interface SortChangeEvent {
  prop: string;
  order: 'ascending' | 'descending' | null;
}

type SelectionChangeEvent<T = any> = T[];
```

## 注意事项

::callout{type="warning"}
1. `data` 和 `columns` 是必需的属性
2. 使用自定义插槽时，需要在列配置中设置 `slot` 属性
3. 排序功能需要在列配置中设置 `sortable` 属性
4. 组件基于 Element Plus Table，通过 `v-bind="$attrs"` 透传其他 props 和事件
5. 支持 TypeScript 泛型，可以为表格数据指定类型
6. `formatter` 用于简单的文本格式化，`slot` 用于复杂的自定义渲染
::
