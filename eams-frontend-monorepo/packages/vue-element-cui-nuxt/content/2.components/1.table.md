# CuiTable 表格组件

CuiTable 是基于 Element Plus Table 组件封装的增强型表格组件，提供了更简洁的 API 和常用功能的快速配置。

## 基础用法

使用 `data` 和 `columns` 属性定义表格数据和列配置。

```vue
<template>
  <CuiTable :data="tableData" :columns="columns" />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import { CuiTable } from '@eams/vue-element-cui';
import type { CuiTableColumn } from '@eams/vue-element-cui';

const tableData = ref([
  { id: 1, name: 'Alice', age: 25, email: 'alice@example.com' },
  { id: 2, name: 'Bob', age: 30, email: 'bob@example.com' },
]);

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'email', label: '邮箱' },
];
</script>
```

## 索引列

通过 `show-index` 属性显示序号列。

```vue
<CuiTable :data="tableData" :columns="columns" show-index />
```

## 选择列

通过 `show-selection` 属性显示多选框列，并监听 `selection-change` 事件获取选中的行。

```vue
<template>
  <CuiTable
    :data="tableData"
    :columns="columns"
    show-selection
    @selection-change="handleSelectionChange"
  />
</template>

<script setup lang="ts">
const handleSelectionChange = (selection: any[]) => {
  console.log('选中的行:', selection);
};
</script>
```

## 排序

在列配置中设置 `sortable` 属性启用排序功能。

```vue
<template>
  <CuiTable
    :data="tableData"
    :columns="columns"
    @sort-change="handleSortChange"
  />
</template>

<script setup lang="ts">
import type { SortChangeEvent } from '@eams/vue-element-cui';

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名', sortable: true },
  { prop: 'age', label: '年龄', sortable: true },
];

const handleSortChange = (event: SortChangeEvent) => {
  console.log('排序:', event.prop, event.order);
};
</script>
```

## 自定义单元格

通过 `slot` 属性和具名插槽自定义单元格内容。

```vue
<template>
  <CuiTable :data="tableData" :columns="columns">
    <template #status="{ row }">
      <el-tag :type="row.status === 'active' ? 'success' : 'info'">
        {{ row.status === 'active' ? '活跃' : '非活跃' }}
      </el-tag>
    </template>
    <template #actions="{ row }">
      <el-button size="small" @click="handleEdit(row)">编辑</el-button>
      <el-button size="small" @click="handleDelete(row)">删除</el-button>
    </template>
  </CuiTable>
</template>

<script setup lang="ts">
const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'status', label: '状态', slot: 'status' },
  { label: '操作', slot: 'actions' },
];
</script>
```

## 加载状态

通过 `loading` 属性显示加载状态。

```vue
<CuiTable :data="tableData" :columns="columns" :loading="loading" />
```

## 表格样式

通过 `stripe` 和 `border` 属性控制表格样式。

```vue
<CuiTable :data="tableData" :columns="columns" stripe border />
```

## 固定高度

通过 `height` 或 `max-height` 属性设置表格高度。

```vue
<CuiTable :data="tableData" :columns="columns" height="400" />
```

## 固定列

通过在列配置中设置 `fixed` 属性固定列。

```vue
<template>
  <CuiTable :data="tableData" :columns="columns" />
</template>

<script setup lang="ts">
const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名', width: 100, fixed: 'left' },
  { prop: 'address', label: '地址', width: 300 },
  { prop: 'email', label: '邮箱', width: 200 },
  { prop: 'phone', label: '电话', width: 150, fixed: 'right' },
];
</script>
```

## 格式化列内容

通过 `formatter` 属性格式化单元格内容。

```vue
<script setup lang="ts">
const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  {
    prop: 'salary',
    label: '薪资',
    formatter: (row, column, cellValue) => `¥${cellValue.toLocaleString()}`,
  },
  {
    prop: 'createTime',
    label: '创建时间',
    formatter: (row, column, cellValue) => new Date(cellValue).toLocaleDateString('zh-CN'),
  },
];
</script>
```

## 行和单元格点击事件

监听 `row-click` 和 `cell-click` 事件处理行和单元格点击。

```vue
<template>
  <CuiTable
    :data="tableData"
    :columns="columns"
    @row-click="handleRowClick"
    @cell-click="handleCellClick"
  />
</template>

<script setup lang="ts">
const handleRowClick = (row: any, column: any, event: Event) => {
  console.log('行点击:', row);
};

const handleCellClick = (row: any, column: any, cell: any, event: Event) => {
  console.log('单元格点击:', row, column.property);
};
</script>
```

## 自定义排序

设置 `sortable: 'custom'` 实现自定义排序逻辑。

```vue
<template>
  <CuiTable
    :data="sortedData"
    :columns="columns"
    @sort-change="handleSortChange"
  />
</template>

<script setup lang="ts">
import { ref, computed } from 'vue';

const tableData = ref([...]);
const sortConfig = ref({ prop: '', order: null });

const sortedData = computed(() => {
  if (!sortConfig.value.order) return tableData.value;

  return [...tableData.value].sort((a, b) => {
    const prop = sortConfig.value.prop;
    const order = sortConfig.value.order === 'ascending' ? 1 : -1;
    return (a[prop] > b[prop] ? 1 : -1) * order;
  });
});

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名', sortable: 'custom' },
  { prop: 'age', label: '年龄', sortable: 'custom' },
];

const handleSortChange = (event: SortChangeEvent) => {
  sortConfig.value = event;
};
</script>
```

## API 参考

### CuiTableProps

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| data | 表格数据 | `T[]` | `[]` |
| columns | 列配置 | `CuiTableColumn<T>[]` | `[]` |
| loading | 是否显示加载状态 | `boolean` | `false` |
| showIndex | 是否显示索引列 | `boolean` | `false` |
| showSelection | 是否显示选择列 | `boolean` | `false` |
| stripe | 是否显示斑马纹 | `boolean` | `false` |
| border | 是否显示边框 | `boolean` | `true` |
| height | 表格高度 | `string \| number` | - |
| maxHeight | 表格最大高度 | `string \| number` | - |

### CuiTableColumn

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| prop | 列属性名 | `string` | - |
| label | 列标题 | `string` | - |
| width | 列宽度 | `string \| number` | - |
| minWidth | 最小列宽度 | `string \| number` | - |
| sortable | 是否可排序 | `boolean \| 'custom'` | `false` |
| fixed | 列是否固定 | `boolean \| 'left' \| 'right'` | `false` |
| align | 对齐方式 | `'left' \| 'center' \| 'right'` | `'left'` |
| formatter | 格式化函数（用于简单的文本格式化） | `(row, column, cellValue, index) => string \| number` | - |
| slot | 自定义插槽名称（用于复杂的自定义渲染） | `string` | - |

### Events

| 事件名 | 说明 | 回调参数 |
| --- | --- | --- |
| sort-change | 排序变化时触发 | `{ prop: string, order: 'ascending' \| 'descending' \| null }` |
| selection-change | 选择变化时触发 | `selection: T[]` |
| row-click | 行点击时触发 | `(row: T, column: any, event: Event)` |
| cell-click | 单元格点击时触发 | `(row: T, column: any, cell: any, event: Event)` |

::callout{type="info"}
组件通过 `v-bind="$attrs"` 透传其他 Element Plus Table 的 props 和事件，因此支持所有 ElTable 的原生事件。
::

### Slots

| 插槽名 | 说明 | 参数 |
| --- | --- | --- |
| [column.slot] | 自定义单元格内容 | `{ row: T, column: CuiTableColumn, $index: number }` |

## 类型定义

```typescript
interface CuiTableColumn<T = any> {
  prop?: string;
  label: string;
  width?: string | number;
  minWidth?: string | number;
  sortable?: boolean | 'custom';
  fixed?: boolean | 'left' | 'right';
  align?: 'left' | 'center' | 'right';
  formatter?: (row: T, column: any, cellValue: any, index: number) => any;
  slot?: string;
}

interface CuiTableProps<T = any> {
  data: T[];
  columns: CuiTableColumn<T>[];
  loading?: boolean;
  showIndex?: boolean;
  showSelection?: boolean;
  stripe?: boolean;
  border?: boolean;
  height?: string | number;
  maxHeight?: string | number;
}

interface SortChangeEvent {
  prop: string;
  order: 'ascending' | 'descending' | null;
}

type SelectionChangeEvent<T = any> = T[];
```

## 注意事项

::callout{type="warning"}
1. `data` 和 `columns` 是必需的属性
2. 使用自定义插槽时，需要在列配置中设置 `slot` 属性
3. 排序功能需要在列配置中设置 `sortable` 属性
4. 组件基于 Element Plus Table，通过 `v-bind="$attrs"` 透传其他 props 和事件
5. 支持 TypeScript 泛型，可以为表格数据指定类型
6. `formatter` 用于简单的文本格式化，`slot` 用于复杂的自定义渲染
::
