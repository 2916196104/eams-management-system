# CuiRadioEnum 组件

CuiRadioEnum 是一个基于枚举代码的单选框组件，自动加载枚举选项。

## 基础用法

```vue
<template>
  <CuiRadioEnum
    v-model="value"
    enum-code="USER_STATUS"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import { CuiRadioEnum } from '@eams/vue-element-cui';

const value = ref('');
</script>
```

## Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| modelValue | any | - | 绑定值 |
| enumCode | string | - | 枚举代码 |
| disabled | boolean | false | 是否禁用 |

## Events

| 事件名 | 说明 | 回调参数 |
|--------|------|---------|
| update:modelValue | 值变化时触发 | (value: any) |
| change | 值变化时触发 | (value: any) |

## CuiRadioEnumOption 接口

```typescript
interface CuiRadioEnumOption {
  label: string;
  value: string;
}
```

## 说明

- 组件会在挂载时自动加载指定 `enumCode` 的枚举选项
- 实际的枚举加载逻辑需要根据项目的枚举系统实现
- 支持与 Element Plus 的 Radio 组件相同的所有功能
