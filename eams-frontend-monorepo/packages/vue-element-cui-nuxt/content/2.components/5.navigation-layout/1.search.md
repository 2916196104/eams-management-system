# CuiSearch

`CuiSearch` 用于承载列表页顶部的筛选与查询动作，关键在于高频条件收敛与结果区联动。

::api-table{title="核心 Props" description="搜索区常用配置"}
| 属性 | 类型 | 说明 |

| `modelValue` | `Record<string, any>` | 当前查询条件 |
| `inline` | `boolean` | 是否行内布局 |
| `collapsible` | `boolean` | 是否支持高级筛选折叠 |
