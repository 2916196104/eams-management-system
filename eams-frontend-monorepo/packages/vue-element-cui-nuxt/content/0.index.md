# Vue Element CUI

企业级 Vue 3 组件库，基于 Element Plus 封装，提供更简洁的 API 和常用功能的快速配置。

::callout{type="info"}
Vue Element CUI 专为企业资产管理系统（EAMS）设计，提供开箱即用的表格、表单、搜索等核心组件。
::

## 核心特性

- **简洁 API**：基于 Element Plus 封装，提供更简洁易用的组件接口
- **TypeScript 支持**：完全使用 TypeScript 编写，提供完整的类型定义
- **企业级组件**：专注于企业应用场景，提供表格、表单、搜索等核心组件
- **高度可定制**：支持灵活的配置和扩展
- **开箱即用**：内置常用功能，减少重复代码

## 快速开始

::code-group

```bash [pnpm]
pnpm add @eams/vue-element-cui
```

```bash [npm]
npm install @eams/vue-element-cui
```

```bash [yarn]
yarn add @eams/vue-element-cui
```

::
