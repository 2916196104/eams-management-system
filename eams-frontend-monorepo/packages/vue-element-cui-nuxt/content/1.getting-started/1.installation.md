# 安装

使用您喜欢的包管理器安装 Vue Element CUI。

## 包管理器安装

::code-group

```bash [pnpm (推荐)]
pnpm add @eams/vue-element-cui
```

```bash [npm]
npm install @eams/vue-element-cui
```

```bash [yarn]
yarn add @eams/vue-element-cui
```

::

## 依赖要求

Vue Element CUI 依赖以下库：

- **Vue 3**：`^3.3.0` 或更高版本
- **Element Plus**：`^2.0.0` 或更高版本

::callout{type="warning"}
请确保您的项目已安装 Vue 3 和 Element Plus。
::

## 安装 Element Plus

如果您的项目还没有安装 Element Plus，请先安装：

::code-group

```bash [pnpm]
pnpm add element-plus
```

```bash [npm]
npm install element-plus
```

```bash [yarn]
yarn add element-plus
```

::

## 样式导入

组件库依赖 Element Plus 样式，请确保在项目中导入：

```typescript
// main.ts 或 main.js
import 'element-plus/dist/index.css'
import '@eams/vue-element-cui/dist/vue-element-cui.css'
```

## TypeScript 支持

Vue Element CUI 完全使用 TypeScript 编写，提供完整的类型定义。安装后即可直接使用类型：

```typescript
import type { CuiTableColumn, CuiFormField } from '@eams/vue-element-cui'
```
