# 安装

## 依赖

```bash
pnpm add @eams-monorepo/vue-element-cui element-plus
```

## 样式接入

在入口样式文件中引入组件库样式：

```ts
import "@eams-monorepo/vue-element-cui/dist/style.css";
```

## 注册方式

如果没有做全局注册，可以在页面或业务组件中按需引入。

::doc-note{title="检查点" tone="info"}
安装完成后，优先先跑通一个最小表格或表单 demo，确认组件和样式都已经生效。
::
