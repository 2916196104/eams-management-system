# 快速开始

下面示例展示如何在页面中直接使用 `CuiTable`。

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CuiTable } from "@eams/vue-element-cui";

const rows = ref([
	{ name: "固定资产", status: "启用" },
	{ name: "库存物料", status: "停用" },
]);

const columns = [
	{ prop: "name", label: "名称" },
	{ prop: "status", label: "状态" },
];
</script>

<template>
	<CuiTable :data="rows" :columns="columns" />
</template>
```

跑通最小示例后，再按页面职责拆到表格、表单、选择器等体系页。
