# 快速开始

本指南将帮助您快速上手使用 Vue Element CUI 组件库。

## 全局注册

在您的 `main.ts` 或 `main.js` 中注册 Element Plus：

```typescript
import { createApp } from 'vue'
import App from './App.vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import '@eams/vue-element-cui/dist/vue-element-cui.css'

const app = createApp(App)
app.use(ElementPlus)
app.mount('#app')
```

::callout{type="info"}
Vue Element CUI 组件无需全局注册，可以直接按需导入使用。
::

## 按需导入（推荐）

推荐使用按需导入以减小打包体积：

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { CuiTable, CuiForm } from '@eams/vue-element-cui'
import type { CuiTableColumn, CuiFormField } from '@eams/vue-element-cui'

const tableData = ref([
  { id: 1, name: '张三', age: 25 },
  { id: 2, name: '李四', age: 30 }
])

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' }
]

const formData = ref({
  name: '',
  email: ''
})

const fields: CuiFormField[] = [
  { prop: 'name', label: '姓名', type: 'input', required: true },
  { prop: 'email', label: '邮箱', type: 'input', required: true }
]
</script>

<template>
  <div>
    <CuiTable :data="tableData" :columns="columns" />
    <CuiForm :model="formData" :fields="fields" />
  </div>
</template>
```

## TypeScript 支持

组件库提供完整的类型定义，可以直接导入使用：

```typescript
import type {
  CuiTableColumn,
  CuiFormField,
  CuiFormRule
} from '@eams/vue-element-cui'

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' }
]
```

## 基础示例

### 表格示例

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { CuiTable } from '@eams/vue-element-cui'
import type { CuiTableColumn } from '@eams/vue-element-cui'

const tableData = ref([
  { id: 1, name: 'Alice', age: 25, email: 'alice@example.com' },
  { id: 2, name: 'Bob', age: 30, email: 'bob@example.com' }
])

const columns: CuiTableColumn[] = [
  { prop: 'name', label: '姓名' },
  { prop: 'age', label: '年龄' },
  { prop: 'email', label: '邮箱' }
]
</script>

<template>
  <CuiTable :data="tableData" :columns="columns" />
</template>
```

### 表单示例

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { CuiForm } from '@eams/vue-element-cui'
import type { CuiFormField } from '@eams/vue-element-cui'

const formData = ref({
  name: '',
  email: '',
  age: null
})

const fields: CuiFormField[] = [
  {
    prop: 'name',
    label: '姓名',
    type: 'input',
    required: true
  },
  {
    prop: 'email',
    label: '邮箱',
    type: 'input',
    required: true
  },
  {
    prop: 'age',
    label: '年龄',
    type: 'input-number'
  }
]

const handleSubmit = () => {
  console.log('表单数据：', formData.value)
}
</script>

<template>
  <CuiForm
    :model="formData"
    :fields="fields"
    @submit="handleSubmit"
  />
</template>
```
